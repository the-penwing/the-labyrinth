## UNIX / MacOS
1. Make a python 3 virtual environment (venv)
```bash
python3 -m venv .venv
```
2. Activate the virtual environment
```bash
source .venv/bin/activate
```
3. Install game dependencies
```bash
pip install -r requirements.txt
```
4. Run the game file
```bash
python3 main.py
```
